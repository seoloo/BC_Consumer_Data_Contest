# 데이터 안내

이 저장소는 공모전 제공 데이터와 그 파생 데이터를 포함하지 않습니다.

분석 재현에는 다음 자료가 필요합니다.

| 자료 | 주요 필드 | 사용 목적 |
|---|---|---|
| BC Card 결제 데이터 | 기준월, 지역, 업종, 연령, 이용금액 | 현재 성장과 연령별 소비비중 계산 |
| 장래인구 | 지역, 연령, 기준연도, 2040년 인구 | Future Stress 계산 |
| NAVER Search와 Shopping Insight | 연령, 검색 관심도, 상품 관심도 | 관심 고객과 상품 후보 해석 |
| 지역별 외부유입 자료 | 지역, 연령 또는 체류유형, 인구 | 민감도 검증 |

외부유입 자료는 지역별로 구조가 다릅니다.

- 서울: 2025년 생활인구 연령구조
- 부산: 2025년 주거, 직장, 방문 생활인구
- 경기: 2026년 1월부터 3월까지의 유동인구 연령구조

세 지역의 검증 결과는 각 지역 안에서만 해석하며 수치를 직접 비교하지 않습니다.
