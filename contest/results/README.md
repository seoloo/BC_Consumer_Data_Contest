# 공개 결과 CSV

이 폴더에는 최종 발표자료에 사용한 소규모 집계 결과만 포함합니다. BC Card 원본, 월별 상세 결제금액, 연령별 상세 이용금액은 포함하지 않습니다.

| 파일 | 내용 |
|---|---|
| `growth_vs_nongrowth_validation.csv` | 성장군과 비성장군의 Future Stress 비교 |
| `statistical_validation.csv` | Mann-Whitney U 검정 결과 |
| `size_threshold_sensitivity.csv` | 규모 기준 변경에 따른 민감도 |
| `stress_test_14_cases_table.csv` | Stress 분석 사례 요약 |
| `representative_3_cases_table.csv` | 대표 전략 사례 요약 |
| `final_4type_customer_strategy.csv` | 4유형별 고객과 상품 전략 |
| `final_3region_robustness.csv` | 서울, 부산, 경기의 지역별 민감도 검증 요약 |

서울, 부산, 경기의 외부유입 데이터는 기간과 구조, 보정 방식이 다르므로 지역 간 수치를 직접 비교하지 않습니다.
