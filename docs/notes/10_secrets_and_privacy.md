# 10. 인증정보 · 비공개 데이터

## 한 줄 요약

인증키는 코드에 쓰지 않고 환경변수 · `.env`에서만 읽습니다. 공모전 원본과 원본에서 나온 데이터는 저장소에 올리지 않고, 발표에 이미 공개한 집계 결과만 올립니다.

## 왜 필요했나

- 노트북에는 NAVER API 인증정보가 셀 안에 직접 적혀 있었습니다. 공개 저장소에 올리면 누구나 그 키를 쓸 수 있습니다. 공개용 노트북은 정리 스크립트(`contest/scripts/`)로 인증정보와 실행 출력을 지운 뒤 올렸습니다.
- BC카드 원본은 공모전에서 받은 데이터라 재배포할 수 없습니다. 지역 × 업종 × 연령 결제 금액이 자세히 남은 중간 결과도 원본을 다시 만들어 낼 수 있어 공개하면 안 됩니다.

## 어떻게 했나

| 대상 | 처리 |
|---|---|
| API 인증키 | 환경변수 또는 저장소 루트의 `.env`에서만 읽음. `.env.example`에는 이름만 적음 (`KOSIS_API_KEY=`) |
| `.env` | `.gitignore`에 등록 (`.env`, `.env.*`, 단 `.env.example`은 올림) |
| 다른 프로젝트와 같은 키 | 복사하지 않고 `--env-file`로 그 프로젝트의 `.env`를 가리킴 |
| 로컬 저장소 계정 키 | `object_store init-env`가 무작위로 만들어 `.env`에만 저장. 화면에 출력하지 않음. 컨테이너는 시작할 때 환경변수로 받음 (이미지 · compose 파일에 키 없음) |
| 저장소 접속 범위 | `127.0.0.1:59100`에만 열어 이 PC 밖에서는 접속 불가 |
| DB 비밀번호 | `local_env`가 무작위로 만들어 `.env`에만 저장. PostgreSQL도 `127.0.0.1:55532`에만 열림. 연결 실패 메시지는 연결 정보를 빼고 한 줄로만 |
| 오류 메시지 | requests 오류의 URL에 인증키가 들어 있어 그대로 올리지 않음 (08 참고) |
| 원본 · 층 데이터 | `data/raw`, `data/bronze`, `data/silver`, `data/gold`, `data/synthetic`, `output/`, `*.csv` · `*.xlsx` 모두 git 제외. `contest/results/*.csv`(발표에 공개한 집계)만 예외로 올림 |
| 원본이 없는 사람 | 합성 데이터로 같은 과정을 돌릴 수 있게 함 (11 참고). 숫자는 원본에서 가져오지 않음 |
| 데이터 안내 | `data/README.md`에 필요한 자료, 공개하지 않는 이유, 재현 방법을 적음 |

## 써 보고 확인한 것

- KOSIS 키를 다른 프로젝트의 `.env`에서 쓰려 할 때, 키 값을 화면에 띄우지 않고도 "값이 비어 있다"는 사실만 확인할 수 있었습니다. 키를 직접 다루지 않아도 되도록 오류 메시지를 설계한 덕분입니다.
- 합성 데이터 덕분에 원본을 공개하지 않고도 저장소만 받은 사람이 전체 파이프라인을 끝까지 돌릴 수 있습니다.

## 다른 방법과 고르지 않은 이유

| 방법 | 고르지 않은 이유 |
|---|---|
| 키를 코드나 설정 파일에 적고 저장소는 비공개로 | 저장소를 공개로 바꾸거나 다른 사람과 공유하는 순간 키가 노출됩니다. git 기록에도 영원히 남습니다 |
| python-dotenv 라이브러리 | 필요한 기능이 "한 줄에서 KEY=VALUE 읽기" 정도라 직접 읽었습니다. BOM, `export`, 줄 끝 주석만 처리하면 됩니다 |
| 원본 일부를 샘플로 공개 | 일부라도 재배포에 해당할 수 있습니다. 형식만 같고 숫자는 직접 정한 합성 데이터가 안전합니다 |

## 스스로 점검할 질문

<details><summary>Q1. 키를 코드에 쓰면 안 되는 이유는? 저장소가 비공개여도?</summary>

비공개 저장소도 나중에 공개로 바뀌거나, 다른 사람이 받거나, 로그 · 오류 메시지로 새어 나갈 수 있습니다. git 기록에 한 번 들어가면 파일을 지워도 기록에 남아 있습니다. 키는 코드와 분리해 실행 환경에서 넣는 것이 원칙입니다.
</details>

<details><summary>Q2. 원본에서 나온 중간 결과도 공개하지 않는 이유는?</summary>

지역 × 업종 × 연령 단위의 결제 금액은 원본을 거의 그대로 다시 만들어 낼 수 있습니다. 발표에 이미 공개한 수준의 집계(결과 표 6개)만 올렸습니다.
</details>
